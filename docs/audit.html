What this is (and isn't): function-level triage from a pre-computed compatibility dataset — LibreOffice verdicts from formulas we executed in real LibreOffice builds, Google Sheets verdicts from the same formulas executed in Sheets via Drive import (a dated run: Sheets has no version to pin), and Excel verdicts from Microsoft's official documentation. It flags functions known to be missing or to behave differently; it does not recalculate your workbook in the target app, so it cannot promise your specific numbers survive. Use it to know where to look first. LibreOffice verdicts are per tested release: we executed every tested function in 24.2.0.3, 24.8.7.2, 25.2.0.3 and 25.8.7.3, so picking an older target version above flags functions that only exist in newer builds. Google Sheets has no version to target — one dated run, and a handful of functions whose verdict is inconclusive because the .xlsx storage prefix we write was not mapped by Google's importer; those fall back to Google's documentation and say so.
