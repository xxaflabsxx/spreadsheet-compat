Why isn’t MONTHS working in Google Sheets?

Google Sheets does not implement MONTHS: we imported the formula into Sheets on 2026-09-01 and every case came back #NAME? (unrecognized function). Sheets is a rolling service with no version to pin, so this is a statement about the service on that date, and Google’s own function list does not document it either. Rewrite the formula with a documented Sheets equivalent — see the Excel ↔ Sheets equivalents table.
