Category: Parser · Last tested 2026-09-01

Why isn't TO_TEXT working in LibreOffice?

LibreOffice Calc does not implement TO_TEXT as of 25.8.7.3 — in our executed tests it returns a #NAME? (unrecognized function) error. This is not a typo or a settings problem, and saving the file as .xlsx does not change it: the function simply isn’t available yet. Watch the LibreOffice version support page — we re-run every test on each new release, so it will flip to Supported here as soon as it lands.
