Discovered quirks

Every case below is a real, executed formula whose result did not match Excel’s documented/expected behavior. This is the flagship content of Can I Spreadsheet?: cross-engine divergence that only shows up when you actually run the formula. Both executed engines are represented — LibreOffice Calc 25.8.7.3 and Google Sheets (Drive import, 2026-08-31) — measured against Microsoft’s documentation, which we do not execute.
